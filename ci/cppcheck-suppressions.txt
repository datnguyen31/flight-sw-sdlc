# cppcheck suppressions for the HK-TM service (docs/coding-standard.md S3).
# One suppression per line: <id>[:<file-glob>]
# missingIncludeSystem: cppcheck cannot see the host's system headers
# (stdbool.h, stdint.h, ...) without a full include-path replica of the
# target toolchain; the compiler itself already enforces these includes.
missingIncludeSystem
# unusedFunction: Init is the RTEMS initialization task, called by the
# kernel through the table confdefs.h generates, which cppcheck cannot see.
# Every other function in src/app has a caller (the task wrappers, Session 7).
unusedFunction:src/app/rtems/init.c
